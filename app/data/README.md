# Справочник городов регионов

`russian_region_cities.json` — локальный справочник названий городов для
раскладки поиска по субъекту России. Он нужен только для превращения одной
пользовательской настройки «искать по области» в конкретные запросы к
Яндекс Картам и 2ГИС; в Google Sheets записывается фактический город компании.

Источник исходных общедоступных наименований: проект `pensnarik/russian-cities`.
Перед обновлением справочника необходимо проверять состав городов и не менять
названия уже используемых региональных настроек без миграции.
